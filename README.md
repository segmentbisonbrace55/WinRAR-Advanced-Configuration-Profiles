## Usage

### For Basic Archive Creation:
1. Launch WinRAR and open the **Profiles** menu.
2. Load the provided profile via **Profiles** → **Load Profile**.
3. Select the source files or folders you wish to archive.
4. Review and adjust compression settings as needed.
5. Click **OK** to create the archive with your selected profile.

### For Context Menu Integration:
1. Open WinRAR and navigate to **Options** → **Settings** → **Integration**.
2. Import the provided context menu configuration file.
3. Select which archive types and operations appear in the right-click menu.
4. Apply the settings and test the context menu in Windows Explorer.
5. Customize the menu items to your preferences.

### For Batch Processing:
1. Open the automation script folder and review the available `.cmd` or `.bat` files.
2. Edit the script to specify source folders and archive parameters.
3. Run the script via command line or Windows Task Scheduler.
4. Monitor the archiving progress through console output.
5. Review logs for any errors or warnings.

### For Encryption & Security:
1. Load an encryption profile from the provided settings.
2. Set your preferred password and encryption method (AES-256, ZIP 2.0).
3. Test the archive with the password for verification.
4. Store passwords securely using the included password management template.
5. Use the SFX templates for creating self-extracting encrypted archives.

### For Backup Automation:
1. Select the backup profile that matches your needs (daily, weekly, monthly).
2. Configure the source paths and destination folder.
3. Set the maximum archive size and split options.
4. Schedule the backup using Windows Task Scheduler.
5. Test the backup by running the script manually.
